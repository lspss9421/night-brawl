# 判定框編輯器使用說明

開啟：`npm run dev` 後打開 http://localhost:5173/editor.html

## 基本流程（每組動作）

1. 上方選「角色」，左側點要做的動作（例如「站輕拳」）。
   - 左側圓點：灰 = 還沒做、橘 = 格數不夠或攻擊招還沒畫紅框、綠 = 完成。數字是「目前格數 / 建議格數」。
2. 按「匯入影格」或直接把 PNG 拖進視窗。檔名會自然排序（`sLP_2` 在 `sLP_10` 前面）。
   - 勾「去除綠幕」會自動把 #00FF00 背景變透明。
   - **AI 把整組動作畫成一排時**：「切成 N 格」保持 0（自動依角色之間的空白切開，AI 排得不平均也沒關係），再設「縮小 N 倍」把 AI 的大像素縮回真正的像素大小（AI 圖通常 3 倍；縮小後角色身高約 100 像素就對了）。
   - 匯入時會自動找腳底點（綠色圓點）。
3. 按「整組自動對齊腳底」，再逐格檢查：打開「前一格殘影」，腳底點應該對齊在同一條綠色虛線上；不準就按 `A` 點腳底位置，或用方向鍵微調。
4. 按「整組自動受擊／推擠框」產生藍框（受擊）與黃框（推擠），再手動修。
5. 攻擊招：在手腳打出去的那幾格，按 `2` 拉出紅色攻擊框。右側會自動算出「發生／持續／收招」影格數。
6. 調整每格「停留」影格數（60 = 1 秒），看右上預覽確認節奏。
7. 按「存到遊戲專案」→ 寫入 `public/assets/characters/<角色>/sheet.png` 與 `data.json`。

## 三種判定框

| 顏色 | 名稱 | 用途 |
|---|---|---|
| 藍 | 受擊框 | 被打到的範圍，通常每格 1～2 個 |
| 紅 | 攻擊框 | 打人的範圍，只畫在出招有效的那幾格 |
| 黃 | 推擠框 | 角色之間互相推開的範圍（腳底附近的身體寬度） |

## 快捷鍵

| 鍵 | 功能 |
|---|---|
| `V` / `1` / `2` / `3` / `A` | 選取、受擊框、攻擊框、推擠框、腳底點 |
| `,` / `.` | 上一格 / 下一格 |
| 方向鍵（Shift ×10） | 微調選取的框；沒選框時微調腳底點 |
| `Delete` | 刪除選取的框 |
| `Ctrl/⌘ + Z`、`Ctrl/⌘ + Shift + Z` | 復原 / 重做 |
| `Space` | 預覽播放 / 暫停 |
| `O` | 前一格殘影開關 |
| 滾輪、右鍵拖曳 | 縮放、移動畫面 |

## 其他

- 編輯內容會自動存在瀏覽器裡（換角色、關掉頁面都不會遺失），但**只有按「存到遊戲專案」遊戲才讀得到**。
- 「下載 sheet.png + data.json」可以把檔案存到電腦備份；「讀取檔案」可以讀回來繼續編輯。
- 「遊戲中放大」是素材像素在遊戲中的倍數（預設 2，角色在遊戲中約 210 像素高）。
- 招式數值（傷害、硬直、防禦方式…）可在右下調整，會一起存進 data.json。
